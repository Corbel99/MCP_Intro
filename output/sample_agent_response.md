**Student request:** python decorator

## Recommended topic: Python Decorators

### Why this topic is relevant

A decorator is a function that wraps another function to add behavior without changing its code. It is applied with the @decorator syntax.

### Review these prerequisites first

- Functions
- Scope
- Functions as arguments

### Key concepts

- Higher-order functions
- Wrapper functions
- The @ syntax
- *args and **kwargs

### Practice idea

Create a decorator that prints a message before and after a function call.

### Common mistakes to avoid

- Forgetting to return the wrapper function
- Calling the function instead of passing it to the decorator
- Forgetting to return the result of the decorated function
